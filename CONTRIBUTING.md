# Contributing

Thanks for helping. Bugs go in [Issues](https://github.com/AxerieSoftware/dotnet-config-wizard/issues/new/choose), ideas go in [Discussions](https://github.com/AxerieSoftware/dotnet-config-wizard/discussions/new?category=ideas), and pull requests are welcome.

[README.md](README.md) lists the commands and the layout. [AGENTS.md](AGENTS.md) lists what every change needs to pass, and [docs/code-style.md](docs/code-style.md) covers the code style. [docs/catalog.md](docs/catalog.md) explains where rule and option data comes from.

Pull requests are squash-merged into `main` once CI passes.
