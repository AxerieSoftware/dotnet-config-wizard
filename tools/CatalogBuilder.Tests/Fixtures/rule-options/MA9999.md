# MA9999 - Sample rule

Some text with `MA9999.not_an_option = true` outside the configuration block.

````csharp
var example = 1;
````

# Configuration

````
# .editorconfig file
# Skip file-local types. default: true
MA9999.exclude_file_local_types = true

# Matching mode. default: Exact
# Allowed values: Exact, Prefix
MA9999.mode = Exact

# Parts to remove. default: none
MA9999.excluded_parts = razor,.

dotnet_diagnostic.MA9999.severity = warning

# Ignore certain symbols. default: none
# Pipe-separated list of wildcard patterns
dotnet_diagnostic.MA9999.excluded_symbol_names = Foo*
````

````
MA9999.after_the_block = true
````
