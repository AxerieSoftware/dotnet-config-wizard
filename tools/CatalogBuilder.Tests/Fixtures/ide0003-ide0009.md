# Member-access qualification preferences (IDE0003 and IDE0009)

| Property                 | Value                                         |
| ------------------------ | --------------------------------------------- |
| **Rule ID**              | IDE0003                                       |
| **Title**                | Name can be simplified                        |
| **Category**             | Style                                         |
| **Subcategory**          | Language rules ('this.' and 'Me.' qualifiers) |
| **Applicable languages** | C# and Visual Basic                           |
| **Options**              | `dotnet_style_qualification_for_field`        |
|                          | `dotnet_style_qualification_for_property`     |

| Property                 | Value                                         |
| ------------------------ | --------------------------------------------- |
| **Rule ID**              | IDE0390, IDE0391                              |
| **Title**                | Make method synchronous                       |
| **Category**             | Style                                         |
| **Applicable languages** | C#                                            |

## Options

### dotnet_style_qualification_for_field

| Property                 | Value                                | Description                         |
| ------------------------ | ------------------------------------ | ----------------------------------- |
| **Option name**          | dotnet_style_qualification_for_field |                                     |
| **Option values**        | `true`                               | Prefer fields to be prefaced        |
|                          | `false`                              | Prefer fields *not* to be prefaced  |
| **Default option value** | `false:suggestion`                   |                                     |

```csharp
// dotnet_style_qualification_for_field = true
this.capacity = 0;
```

```vb
Me.capacity = 0
```
