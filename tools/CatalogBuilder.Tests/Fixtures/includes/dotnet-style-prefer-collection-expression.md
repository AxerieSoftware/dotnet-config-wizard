### dotnet_style_prefer_collection_expression

| Property                 | Value                                       | Description                         |
|--------------------------|---------------------------------------------|-------------------------------------|
| **Option name**          | dotnet_style_prefer_collection_expression   |                                     |
| **Option values**        | `true` &#124; `when_types_exactly_match`        | Prefer when types match exactly.    |
|                          | `when_types_loosely_match`                  | Prefer when types loosely match.    |
|                          | `false` &#124; `never`                          | Disables the rule.                  |
| **Default option value** | `when_types_loosely_match`                  |                                     |
